# Annotations

`qualitative_direct.csv` contains the final reviewed annotations for four models
over the fixed 100-example evaluation subset (400 rows total).

Each row is identified by `model_name` and `sample_index`. `error_label` stores
one or more taxonomy labels separated by `|`, and `Review_Notes` gives a short
rationale. `prediction` contains the Chinese summary generated by the named
model. The remaining columns contain ROUGE, BERTScore, OmniScore, and length
ratio values used in the paper.

Source dialogues and reference summaries are not included. Predictions are
provided for non-commercial research and reproducibility; the applicable model
and dataset terms still apply. See `taxonomy/taxonomy.csv` for label definitions.
