# Raw data

This directory is reserved for the **XSAMSum** data from the
[ClidSum benchmark](https://github.com/krystalan/ClidSum). The dataset is not
redistributed in this repository; request access by following the instructions
in the original ClidSum repository.

Place the test split at `data/raw/test.json`. The experiments use the English
`dialogue` and the Chinese reference `summary_zh`; the source file also contains
`summary` and `summary_de`. The test split used in the paper contained 819
examples.

Do not commit or redistribute the downloaded dataset.
