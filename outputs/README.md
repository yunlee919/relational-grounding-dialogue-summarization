# Outputs

Precomputed artifacts from the paper experiments. Re-run the scripts in `scripts/` to regenerate.

| Path | Description |
|------|-------------|
| `direct/` | Zero-shot SLM Chinese summaries (per model + combined CSV/JSON) |
| `mbart_baseline/` | mBART supervised baseline summaries |
| `metrics/` | Aggregated error rates and automatic metric tables |

Checkpoint (`*_checkpoint.jsonl`) files are excluded from version control.
