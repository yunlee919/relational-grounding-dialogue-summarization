# grounded-semantic-pipeline
Grounded semantic feature extraction from dialogue

The main idea could be to diagnose whether open-weight LLMs can reliably extract structured, source-grounded semantic representations from dialogue. In this work, we define grounding as the extent to which extracted semantic structures are supported by the source dialogue. Our focus is on failures in event-level relations, role filling, and final outcomes, and how these extraction failures can create downstream faithfulness bottlenecks.
