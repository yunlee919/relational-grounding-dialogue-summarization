# grounded-semantic-pipeline
Grounded semantic feature extraction from dialogue

Diagnosing grounded semantic extraction from dialogue using open-weight LLMs.

The main goal of this project is to diagnose whether open-weight LLMs can extract structured, source-grounded semantic representations from dialogue. Rather than focusing only on downstream summarization quality, we analyze the semantic extraction stage itself, including failures in event-level relations, role filling, evidence grounding, and final outcome prediction. We then examine how these extraction failures can create downstream faithfulness bottlenecks in summarization.
